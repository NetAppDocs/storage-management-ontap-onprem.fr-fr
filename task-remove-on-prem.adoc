= Supprimer un système ONTAP sur site de la NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Supprimez un système ONTAP sur site si vous ne souhaitez plus le gérer depuis la console.

.Rôle de console requis :
Administrateur de stockagelink:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["En savoir plus sur les rôles d’accès à la NetApp Console ."^]

La suppression du système n’affecte pas le cluster ONTAP .  Vous pouvez le redécouvrir depuis la Console à tout moment.

.Étapes
. Dans le menu de navigation, sélectionnez *Stockage > Gestion*.
. Sélectionnez le système ONTAP sur site sur la page *Systèmes*.
. Sélectionnez l'icône de menu et sélectionnez *Supprimer de l'espace de travail*.
. Sélectionnez *Supprimer* pour confirmer.
